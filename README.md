# homebrew-lazydap

Homebrew tap for [lazydap](https://github.com/planetaryescape/lazydap), a scriptable,
terminal-first debugger.

```sh
brew install planetaryescape/lazydap/lazydap
```

lazydap needs codelldb on your PATH via a wrapper script — the
[install docs](https://lazydap.sh/getting-started/install/) have the four commands.

The formula is rendered and pushed by lazydap's release workflow; changes belong in
[`packaging/homebrew/`](https://github.com/planetaryescape/lazydap/tree/main/packaging)
in the main repository, not here.
